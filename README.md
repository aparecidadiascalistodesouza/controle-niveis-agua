# Controle de Níveis de Água

## Descrição
Este projeto foi desenvolvido em Python para simular o monitoramento dos níveis de água de um reservatório, exibindo mensagens de alerta com cores diferentes conforme o nível informado.

## Objetivo
Praticar o uso de listas, funções, estruturas condicionais, laços de repetição e bibliotecas em Python.

## Tecnologias utilizadas
- Python
- Biblioteca Colorama

## Níveis do reservatório

- **Nível 1:** Muito baixo (crítico) — vermelho.
- **Nível 2:** Baixo — amarelo.
- **Nível 3:** Médio — verde.
- **Nível 4:** Alto — ciano.
- **Nível 5:** Muito alto (alerta) — azul.

## Instalação

Instale a biblioteca Colorama pelo terminal:

```bash
python -m pip install colorama
```

## Como executar

No terminal, dentro da pasta do projeto, execute:

```bash
python controle_niveis_agua.py
```

## Funcionamento

O programa utiliza uma lista para armazenar as mensagens dos cinco níveis e uma função para definir a cor de cada alerta. Os níveis são simulados por valores definidos no código.
